# iCloud 隐私邮箱助手（单浏览器版）

这是独立的浏览器扩展，只操作当前浏览器中打开的 `account.apple.com` 页面。

## 使用

1. 在 Edge 或 Chrome 的扩展管理页打开开发者模式。
2. 选择“加载已解压的扩展”，目录选择本文件夹。
3. 打开 Apple 隐私邮箱地址列表页。
4. 点击扩展图标，打开运行开关并开始生成。

本版本不连接协调服务，不显示其他浏览器，不支持多浏览器并行。生成结果和本浏览器历史保存在扩展本地存储中。

## 注意

- 不需要启动 `coordinator` 服务。
- 更新文件后，在扩展管理页点击“重新加载”。
- 验证码、Apple 登录和页面授权仍需在当前浏览器中手动完成。
